# Footage

Which recordings of real phones were measured, and the tools that measured them. Used to fit the motion values labelled **Fitted** in the [design docs](../../design/README.md#source-labels).

The frames themselves come from other people's videos, so they are kept in `docs/evidence/private/footage/`, outside this repository (see the [evidence README](../README.md#private-files)).

## Tools

The Swift scripts in [`tools/`](tools) read a video with AVFoundation, so they run on macOS without ffmpeg. Compile one with `swiftc -O tools/rect.swift -o /tmp/rect`, or run it with `swift tools/rect.swift …`. The ones that read a video take its path from `VIDEO` (`probe.swift` takes it as an argument), for example `VIDEO=/path/to/video.mp4 swift tools/track.swift …`.

| Tool | Does |
|---|---|
| `probe.swift` | Prints a video's tracks, size, frame rate and duration |
| `dump.swift` | Decodes every frame of a time range to raw 8-bit grey (or yellowness with `y`) at 1/n size, plus a `.t` file of frame times, for analysis in Python/numpy. The frames are unrotated (landscape); `np.rot90(a, k=-1, axes=(1, 2))` turns them upright |
| `quad.swift` | Flood-fills the lit phone screen from a seed point and prints its four corners |
| `rect.swift` | Rectifies the screen quad (`QUAD`) to a straight 480 × 853 image for each frame in a time range, writes `f_<ms>.png` (milliseconds into the video, zero-padded to six digits) and a contact sheet |
| `sheet.swift` | Contact sheet of a time range, optionally cropped |
| `track.swift`, `segs.swift`, `lines.swift`, `lines2.swift` | Per frame, find coloured or bright regions, column segments or text lines inside a region, to time when rows and tiles move |
| `tiles.swift` | Finds tiles in a reference frame and reports when each starts to move and when it is gone (or appears and settles); used for the Start feather |
| `pngscan.swift`, `pscan2.swift`, `edgescan.swift`, `vext.swift` | Measure rectified frames: the background panel's edges, the title and header positions, vertical extents; used for the hub intro samples in [`../fits`](../fits) |

## Regenerating the hub comparison

`npm run docs:assets -- footage` needs the rectified WP8 frames. Produce them with `rect.swift` from `38SziMGTUiw` (the Games hub starts at 98.665 s), then point `WP8_FOOTAGE_FRAMES` at the folder (default `/tmp/wp8-vid/g1`):

```sh
WP8_FOOTAGE_FRAMES=/path/to/frames npm run docs:assets -- footage
```

The script matches each sample time (0, 67, 133 … 1333 ms after the hub first shows) to the nearest `f_<ms>.png`, films the recreation's hub intro at the same offsets, and writes `docs/evidence/private/footage/hub-intro-compare.jpg`.
